# Вітраж на світлій стіні — фінальна специфікація «Код міста» (v4, після другої рецензії)

Інтерфейс — одне вітражне вікно на світлій паперовій стіні. Стіна — теплий папір #e5e2d9 (серцевина deco-atom і зернисте тло обкладинки), панелі — біле скло #f7f6ec (колір «прогалини паперу» на штанах персонажів) у рівній вугільній оправі 1.5px #30302e — тій самій лінії, якою обведені персонажі (0.7 % висоти фігури). Колір з'являється лише там, де «вмикається світло у вікні»: кнопка дії, правильна відповідь, значок балу, засвічені вікна прогресу — плоскі бірюзові площини, точна цитата вікон #226a7a на вершкових фасадах cover.jpg. Світлий шов 1px #f7f6ec існує тільки всередині бірюзових (увімкнених) панелей як «біла складка» з одягу персонажів; на білому склі шва немає, тому подвійної рамки не виникає. Справжня смальта (cover, deco-sputnik/atom, river-h, персонажі) — єдині об'єкти з фактурою й бліком; вона лежить у «ложі» 4px затирки #bcc1ba, як по краю deco-arch, і ніколи не імітується CSS-ом. Бірюзова тріада домінює (25–30 % площі), теракота #d36d47 лише як намистина «ви тут», цегла #92221b лише як оправа й позначка хибної відповіді, бурий #461713 лише як тонка лінія-п'єдестал над футером (тієї ж товщини, що й оправи — на сторінці немає жодної лінії товщою за --lead-w). Жодних тіней, градієнтів (крім одного еліптичного бліка на кулі балу), пастелей, крему (#f2d68a — шкіра персонажів — не з'являється ні в UI, ні в OG), радіусів 8–16px: дві родини форм — панель r=4px і коло r=999 (літери-намистини, значок, маркер). Стани — світло: панель вмикається (бірюза), гасне (прозоре скло з сірою затиркою) або тріскається (цегляна оправа). Декор ніколи не виходить за margin-box свого блоку: виступ декору над карткою завжди менший за її margin-top мінімум на 8px. Зерно (.grain) лежить ТІЛЬКИ на стіні під контентом: воно ніколи не накладається на панелі, кнопки й мозаїку.

Джерело істини для кольорів — hex у цій специфікації та в vitrazh.css. Довідковий файл palette.json (частки кольорів у ілюстраціях: вікна #226a7a 14.3 %, серцевина атома #e5e2d9 19.9 %, шкіра #f2d68a 12.7 % у хранительки / 8.4 % у туриста) закомітити з сесійного scratchpad у kod-mista/docs/palette.json разом зі скриптом, який його згенерував (docs/palette.mjs); частки в спеці — лише аргументація вибору, не вимога до коду.

Правило контрасту на бірюзі: на #72aab5 текст лише --ink #30302e. Перевірені контрасти (WCAG, перераховані): #30302e на #72aab5 — 5.1:1; #f7f6ec на #226a7a — 5.7:1; #f7f6ec на #0e4758 — 9.4:1; #414a4b на #e5e2d9 — 7.0:1; #414a4b на #f7f6ec — 8.4:1; #414a4b на #72aab5 — 3.5:1 (на бірюзі --ink-2 заборонений); #0e4758 на #72aab5 — 3.95:1, ЗАБОРОНЕНО (жоден hover/active/isOpen/isCopied не має давати цю пару); #30302e на #e5e2d9 — 10.2:1; #30302e на #f7f6ec — 12.2:1; #414a4b на #d7d6cf (футер) — 6.3:1; #30302e на #d7d6cf — 9.1:1; #f2d68a на #0e4758 — 7.2:1 (AA проходить, але крем у UI заборонений принципом «без крему», тому текст на кулі балу — --glass). Нетекстові контрасти на стіні #e5e2d9 (WCAG 1.4.11, ≥3:1): оправа next-вікна #414a4b — 7.0:1; оправа now-вікна #30302e — 10.2:1; заливка done-вікна #226a7a — 4.75:1; оправа панелей #30302e — 10.2:1; #a9adaa на стіні — 1.75:1, тому затирка #a9adaa — лише для згаслих (off) станів і роздільників, ніколи для елементів, які мусять розрізнятися.

Передумова здачі (контент, окреме завдання, скін не блокує): пояснення питань 1, 2, 3, 4 і 7 у data/quiz.ts мають 394 / 314 / 361 / 331 / 363 символи — нижче вимоги 400–600; потрібна редактура редактором/замовницею до 400–600 символів, перше речення — головна думка. Скін приймається з поточними текстами, тест здається після редактури.

## Типографіка
Гарнітури лише з /public/fonts/hm (globals.css): Lora 400/500/700 + Lora Italic 400, Open Sans 400/500/700. Жодного uppercase, жодних декоративних номерів. Трекінг — одне правило: Lora ≥36px — letter-spacing −0.01em; Lora 22–30px — −0.005em; решта (Lora <22px, увесь Open Sans) — 0. Розміри «375 / 1440», line-height у px; у проміжку 376–899 діють значення 375. Усі тексти — з data/quiz.ts як є; нові рядки, яких у data немає, — лише у блоці «Тексти на затвердження» (див. нижче): групи 1–2 до схвалення не рендеряться, група 3 (UI-хром) рендериться, але показана замовниці списком.

## Рух
Усе — «світло вмикається», без пружин, підстрибувань, масштабу >1 і тіней; одна крива cubic-bezier(.2,.7,.2,1); @media (prefers-reduced-motion: reduce) — усі transition/animation none, прокрутка миттєва (на ту саму позицію top − 64 / −48), лічильник показує кінцеве число.
• Hover/active/focus панелей, кнопок, плиток і вордмарка: background-color, border-color, color 120ms. Без transform.
• Поява екрана питання: .qpane і 4 варіанти — opacity 0→1 + translateY(6px→0), 240ms, stagger 40ms (панель, А, Б, В, Г; разом ≤400ms) — «плитки лягають одна за одною».
• Відповідь (один тап): обраний варіант отримує background #72aab5 (текст --ink) миттєво; через 80ms усі чотири перефарбовуються одночасно за 240ms (правильний вмикається, хибний отримує цегляну оправу, решта гаснуть) і стають disabled. Літера → SVG ✓/✗ без анімації. Поточне вікно прогресу переходить now → done (заливка #f7f6ec, оправа #30302e → заливка й оправа #226a7a) за 240ms із затримкою 100ms.
• Картка пояснення: opacity 0→1 + translateY(8px→0), 240ms, одразу після перефарбування (без паузи); деко на її оправі — лише opacity 0→1 за 320ms із затримкою 120ms, без руху. Прокрутка до картки — у тому ж кадрі (useLayoutEffect + glide(top − 64 / −48, 320ms)), не чекаючи анімації.
• Зміна питання: без exit-анімації (Sheet ремонтується за key={q.id}, рушій перемикає idx синхронно — старий блок зникає миттєво); новий — stagger як вище; scrollTo top миттєво; у ряду вікон наступне вікно next → now (заливка #d7d6cf → #f7f6ec, оправа 1px #414a4b → --lead-w #30302e) за 240ms.
• Результат: персонаж opacity 0→1 за 320ms (пам'ятник не рухається); підвіконня заливається зліва направо scaleX 0→1 за 400ms (transform-origin left) одночасно з персонажем; значок балу через 160ms — opacity 0→1 + scale .96→1 за 280ms, число рахується 0→N за 600ms ease-out (CountUp уже є; reduced-motion — одразу N); звання — opacity 240ms через 240ms; маркер «ви тут» через 400ms переїжджає translateX від лівого краю шкали до поточної панелі за 400ms один раз, панель вмикається (тло → #72aab5, текст лишається --ink) наприкінці переїзду; плитки «Ваші відповіді» — opacity 160ms stagger 30ms.
• Плитки: розгортання/згортання картки під сіткою — opacity 0→1 + translateY(6px→0) 240ms; закриття миттєве; зміна відкритої плитки — стара картка зникає без анімації, нова з'являється як вище.
• Копіювання: текст міняється миттєво, тло 120ms (→ #72aab5, текст --ink), повернення через 1500ms.
• Атом-спінер: spin 12s linear infinite — єдина нескінченна анімація, лише під час завантаження результату.
