# Код міста

Тест для «Хмарочоса»: вісім питань про будівлі, назви вулиць і пам’ятники.
Текстовий, з однією ілюстрацією на обкладинці; шрифти сайту Хмарочоса — Open Sans і Lora.

- Прод (GitHub Pages): https://yakovina.github.io/kod-mista/
- Концепт-полотно з усіма варіантами дизайну: https://claude.ai/artifact/FQLSs6gbndW6bUuZrhcAE3

## Команди

```bash
npm run dev            # локально, http://localhost:3000
npm run build          # статична збірка в out/ під /kod-mista
npm run build:partner  # збірка під hmarochos.kiev.ua/partner/kod-mista
npm run deploy         # збірка + публікація в гілку gh-pages

npm run og             # перегенерувати OG-картинки (потрібен Google Chrome)
```

## Будова

- `data/quiz.ts` — увесь контент: питання, пояснення, джерела, рівні. Від скіна не залежить.
- `app/useQuiz.ts` — рушій: екрани, бали, перехід між питаннями, статистика.
- `app/skins/` — скіни: `veselka` (за замовчуванням — «Мемфіс на світлій стіні»: кольорові блоки з палітри ілюстрацій, стрічка-веселка з арки, стікери; специфікація в `docs/style-veselka.md`), `vitrazh` («вітраж на світлій стіні», `docs/style-vitrazh.md`; виміряна палітра ілюстрацій — `docs/palette.json`), `memphis` і `book` (запасні) («книжка 80-х»: титульний розворот, сторінка збірника задач, «Відповідь: в)», виноски-джерела, вихідні дані). Скін — лише розмітка екранів і CSS.
- `app/r/[level]/` — шер-сторінки результатів з OG-картинками.
- `app/stats.ts` — відправлення статистики в Google Form (вимкнено, доки не заповнено `FORM`).

### Новий скін

1. Скопіювати `app/skins/veselka` у `app/skins/<назва>`, переписати розмітку й CSS (корінь — клас `.<назва>`).
2. Додати його в `SKINS` у `app/skins/index.ts` і підключити CSS у `app/layout.tsx`.
3. Зібрати з `NEXT_PUBLIC_SKIN=<назва> npm run build`.

Ідеї скінів чекають на полотні: «Авангард», «Калька», «Слово», чисті кольори, вулична табличка.

## Ілюстрації

Усі в `public/art/`, прозоре тло, webp: `cover.jpg` (обкладинка), `deco-*.webp` (супутник, атом, арка, річки, жар-птиця, космонавт), `char-{tourist,citizen,keeper}.webp` (персонажі рівнів; контейнер на результаті обмежений по висоті, файл показується цілим) і `char-*-560.webp` (1x-версії для srcset).
Після заміни ілюстрацій — `npm run og`, щоб оновити картинки для соцмереж.
